# Stepbro Terminal (beta)

A terminal built for running coding agents like Claude Code and Codex, with sessions that keep running when you close the window.

This is where the installers live. Grab the latest one for your system from the Releases page on the right.

- Windows: the .exe installer
- macOS: the .dmg
- Linux: the .AppImage or .deb

It is early and things will change. If something breaks, open an issue here and tell me what you were doing.
