# stepbro terminal (beta)

A terminal built for running coding agents like Claude Code, Codex and OpenCode, with sessions that keep running when you close the window.

![stepbro terminal on macOS, a folder open and Topito waiting for a new session](assets/stepbro-terminal.png)

## Latest: 0.1.0-beta.28

Short session names, a sidebar that floats out like Arc's, any link in the preview, and the .deb working on Ubuntu 24.04.

- **Windows**: [StepbroTerminal-0.1.0-beta.28-win-x64.exe](https://github.com/kevin9038440334/StepbroTerminal-releases/releases/download/v0.1.0-beta.28/StepbroTerminal-0.1.0-beta.28-win-x64.exe)
- **macOS (Apple Silicon)**: [StepbroTerminal-0.1.0-beta.28-mac-arm64.dmg](https://github.com/kevin9038440334/StepbroTerminal-releases/releases/download/v0.1.0-beta.28/StepbroTerminal-0.1.0-beta.28-mac-arm64.dmg)
- **macOS (Intel)**: [StepbroTerminal-0.1.0-beta.28-mac-x64.dmg](https://github.com/kevin9038440334/StepbroTerminal-releases/releases/download/v0.1.0-beta.28/StepbroTerminal-0.1.0-beta.28-mac-x64.dmg)
- **Linux**: [AppImage](https://github.com/kevin9038440334/StepbroTerminal-releases/releases/download/v0.1.0-beta.28/StepbroTerminal-0.1.0-beta.28-linux-x86_64.AppImage) or [.deb](https://github.com/kevin9038440334/StepbroTerminal-releases/releases/download/v0.1.0-beta.28/StepbroTerminal-0.1.0-beta.28-linux-amd64.deb)

What changed in each version is on the [Releases](https://github.com/kevin9038440334/StepbroTerminal-releases/releases) page. Once installed, the app updates itself.

The builds are not signed yet, so Windows and macOS warn the first time you open them. On Windows click "More info" and then "Run anyway"; on macOS right-click the app and choose "Open".

It is early and things will change. If something breaks, open an issue here and tell me what you were doing.
